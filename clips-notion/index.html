In Notion

  1. Type /embed on the page, paste the link, and press Enter.
  2. Drag the embed's edge to size it. Two-finger swipe scrubs; click plays; arrow keys step frames.
  3. For a live session use the Present link: the toolbar draws over the paused picture and the marks survive a reload.
  4. Share the page publicly with the Public link embedded; players get playback and scrub, no toolbar.

Videos in your CTH folder have no web address, so they cannot be embedded; host the file somewhere with a direct link first.
